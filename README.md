# Расчёт заряда со звездообразным каналом

Проект реализует геометрический и термодинамический расчёт заряда со
звездообразным каналом. Основная математическая модель записана и вычисляется
непосредственно в безразмерных величинах. Реальный диаметр используется только
в отдельном модуле восстановления размерных параметров.

## Обозначения

В расчёте используются следующие величины:

- `N_RAYS` — число лучей $n$;
- `R_BAR` — относительный радиус скругления
  $\bar r=r/R$;
- `E0_BAR_VALUES` — значения относительной толщины свода
  $\bar e_0=2e_0/D$;
- $\bar e=2e/D$ — относительная текущая толщина сгоревшего свода;
- $\widehat R=2R/D$ — безразмерный геометрический радиус;
- $\widehat r=2r/D$ — безразмерный радиус скругления;
- $\bar\Pi=\Pi/D$ — безразмерный периметр горения;
- $\bar F=4F_{\text{кан}}/D^2$ — безразмерная площадь канала.

Безразмерные радиусы определяются непосредственно из входных параметров:

$$
\widehat R=\frac{1-\bar e_0}{1+\bar r},
\qquad
\widehat r=\bar r\widehat R.
$$

В безразмерном расчёте вспомогательное значение диаметра не используется.

## Структура проекта

- `variant_parameters.py` — входные параметры вариантов и настройки
  численных сеток;
- `main.py` — безразмерная математическая модель;
- `calculate_perimeter.py` — построение зависимостей
  $\bar\Pi(\bar e)$;
- `thermodynamic_calculation.py` — расчёт показателей индивидуального
  варианта;
- `subgroup_thermodynamic_calculation.py` — сводный расчёт семи вариантов
  подгруппы;
- `dimensional_parameters.py` — восстановление размерных величин для заданного
  физического диаметра;
- `graf_style.txt` — настройки оформления графиков Matplotlib;
- `requirements.txt` — зависимости Python;
- `output/` — расчётные таблицы и изображения;
- `Указания.pdf` — методические указания.

## Задание варианта

Безразмерные входные данные задаются в `variant_parameters.py`:

```python
N_RAYS = 9
R_BAR = 0.15
E0_BAR_VALUES = (0.30, 0.35, 0.40, 0.45, 0.50, 0.55, 0.60)
```

Параметры `SUBGROUP_VARIANTS` содержат пары
`(r/R, множитель beta*)` для вариантов подгруппы. Параметры
`SELECTED_VARIANT` и `SELECTED_E0_BAR` определяют вариант и точку, выделяемые
на сводной диаграмме.

`POINTS_PER_CURVE` и `INTEGRATION_POINTS` задают плотность численных сеток.
Они не являются параметрами математической модели.

## Восстановление размерных величин

Реальный наружный диаметр задаётся только в `dimensional_parameters.py`:

```python
DIAMETER_MM = 380.0
```

Диаметр не влияет на безразмерные результаты. Он используется для обратного
пересчёта:

$$
\begin{aligned}
e_0 &= \frac{D}{2}\bar e_0,
& R &= \frac{D}{2}\widehat R,
& r &= \frac{D}{2}\widehat r, \\
e_1 &= \frac{D}{2}\bar e_1,
& e_{\max} &= \frac{D}{2}\bar e_{\max}, \\
\Pi &= D\bar\Pi,
& F_{\text{кан}} &= \frac{D^2}{4}\bar F.
\end{aligned}
$$

Модуль рассчитывает $e_0$, $R$, $r$, $e_1$ и $e_{\max}$ в
миллиметрах. Функции `perimeter_from_bar` и `area_from_bar` предназначены для
перевода безразмерных периметров и площадей в размерные.

## Подготовка окружения

Из корня проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Проект использует NumPy и Matplotlib.

## Запуск

Все команды выполняются из корня проекта.

Построение безразмерного периметра горения:

```powershell
python calculate_perimeter.py
```

Термодинамический расчёт индивидуального варианта:

```powershell
python thermodynamic_calculation.py
```

Сводный расчёт вариантов подгруппы:

```powershell
python subgroup_thermodynamic_calculation.py
```

Восстановление размерной геометрии:

```powershell
python dimensional_parameters.py
```

## Результаты

Расчётные сценарии выводят основные параметры и пути к созданным файлам в
консоль. В каталоге `output/` формируются:

- `burning_perimeter.png` — семейство зависимостей
  $\bar\Pi(\bar e)$;
- `thermodynamic_results.csv` — показатели индивидуального варианта;
- `thermodynamic_heatmap.png` — диаграмма индивидуального варианта;
- `subgroup_thermodynamic_results.csv` — сводная таблица подгруппы;
- `subgroup_thermodynamic_heatmap.png` — сводная диаграмма подгруппы.

CSV-файлы используют разделитель `;` и кодировку UTF-8 с BOM.

## Проверка преобразования модели

Безразмерная реализация получена алгебраическим преобразованием исходных
формул. При контрольном сравнении старой и новой записей на 56 сочетаниях
параметров по 5001 точке максимальные абсолютные расхождения для
$\bar\Pi$ и $\bar F$ равны нулю в машинной арифметике.
